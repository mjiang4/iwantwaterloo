# I Want Waterloo

A place to share ideas for a better Waterloo—whether you live here, study here, or wish the city well from afar.

**[Visit iwantwaterloo.com](https://iwantwaterloo.com)**

Share an idea, explore what others imagine, and support the changes you want to see. Each idea plants a tree in a shared digital garden, and each like helps it grow. Everyone is welcome; no account is needed.

## Contribute

Ideas for improving Waterloo belong on the site. Ideas for improving this project are welcome here, too!

- Open an issue with a suggestion, bug report, or design idea.
- Submit a pull request with an improvement.
- Help make the experience clearer, more accessible, and enjoyable on mobile.

Keep contributions thoughtful and focused. The goal is a simple, welcoming way for people to share what Waterloo could become.

## Built with

React, Vinext, React Three Fiber, Three.js, and Cloudflare Workers with D1.
