# Local Draco decoder

These unmodified decoder files come from `three@0.185.1/examples/jsm/libs/draco/gltf`. They are loaded only when the visitor requests the compressed detail model. Hosting them here avoids a third-party decoder request.

Draco is Copyright Google Inc., distributed under the included Apache 2.0 license. Source: https://github.com/google/draco. When updating Three.js, update and verify this decoder set together. Keep the JavaScript files out of application lint/format tooling.
